Pipeline

Incremental update flow

The pipeline treats legal change as a versioning problem, not a document overwrite problem.

01 discover

Find newly published acts

Poll yearly Collection-of-Laws pages and track act numbers, dates, and source hashes.

02 capture

Store source artifacts

Persist HTML, PDF, and any draft ZIP bundles in immutable storage.

03 normalize

Parse provisions

Turn acts into paragraphs, points, letters, and annex segments with stable anchors.

04 compare

Generate structural diffs

Separate true text edits from numbering-only changes and future-effective versions.

05 publish

Expose grounded retrieval

Release a searchable version only after validation and provenance checks pass.
