# Issue #583 disclaimer screenshots

These full-page screenshots are sanitized review evidence for the public
disclaimer page in Slovak, English, and German. They contain no account, case,
or personal data and are generated by:

```powershell
cd frontend/aijurisdictionfronend
npm run test:e2e -- e2e/disclaimer-localization.spec.ts
```

The Playwright test writes its captures to `runs/e2e/`. Reviewed copies are
tracked in this directory so they can be embedded in pull request #584:

- `disclaimer-en.png` — English
- `disclaimer-de.png` — German
